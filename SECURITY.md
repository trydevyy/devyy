# Security policy

Security fixes target the latest stable release. Include the affected version or commit when reporting a vulnerability.

Use GitHub's [private vulnerability reporting form](https://github.com/trydevyy/devyy/security/advisories/new) when available. If the form is unavailable, contact a repository maintainer privately and request a secure reporting channel. Keep vulnerability details out of public issues and pull requests.

Include the affected component, platform, reproduction steps, impact, and any suggested fix. Remove tokens, webhook URLs, workspace data, and other personal information. Maintainers will coordinate verification, a fix, and disclosure with the reporter.
